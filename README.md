# Курс «Микроструктура рынка»

Интерактивный курс для читателя среднего уровня: 12 модулей, 69 уроков. В каждом уроке есть интерактивная модель, тест и список источников. Помимо уроков в курсе есть повторение, итоговые тесты модулей, лаборатория с симуляторами и итоговый проект. Курс написан по материалам из папки «Книги/Исследования» (52 файла). Сами книги и статьи в репозиторий не входят.

## Как открыть

Онлайн: страница GitHub Pages этого репозитория (адрес см. в описании репозитория).

Локально нужен простой веб-сервер: страница использует несколько файлов, а `file://` в части браузеров их не загружает.

```bash
python -m http.server 8765 --directory course
```

После запуска откройте http://localhost:8765. Интернет не нужен: формулы (KaTeX) лежат в `course/vendor/`.

## Что внутри

| Раздел | Что это |
|---|---|
| Уроки | 69 уроков: теория, формулы, числовые примеры, интерактивные модели. Ответы на тесты сохраняются в браузере. |
| Поиск | Поле в верхней панели (клавиша `/`): по урокам, терминам и разделам, с учётом форм слов; найденные слова подсвечиваются в уроке. |
| Что нужно знать | В начале каждого урока список рекомендуемых предыдущих уроков с отметкой «пройдено» (включая уроки модуля Σ). |
| Термины | Подчёркнутые слова в тексте раскрываются по наведению; полный глоссарий — отдельная страница. |
| Повторение | Вопросы из пройденных тестов возвращаются через 1, 3, 7, 16 и 35 дней; ошибка возвращает вопрос сразу. |
| Итоговые тесты | По 10 вопросов на модуль, порог 70%. |
| Лаборатория | Шесть столов: маркет-мейкер (Avellaneda–Stoikov, новости, информированные трейдеры), исполнение крупного ордера (Almgren–Chriss), живой стакан заявок, где можно отправлять рыночные и лимитные заявки, эксперимент про очередь, эксперимент про дисбаланс и аукцион с единой ценой. |
| Проект «Торговая смена» | Четыре этапа: оценка издержек, исполнение под риск-лимит, котирование в плохие дни, проверка на новых данных. В конце — отчёт. |

Модули: Σ повторение математики (обозначения, степени и логарифмы, суммы, производная, интеграл, вероятность, малые приращения, тренажёр по формулам курса; можно пропустить); 0 деривативы и стохастика; 1 рынок и ордера; 2 книга заявок; 3 спред и информация; 4 влияние на цену и издержки; 5 маркет-мейкинг; 6 оптимальное исполнение и риск ликвидности; 7 HFT и процессы Хоукса; 8 манипуляции; 9 другие рынки; 10 стратегии, бэктест, RL.

## Структура репозитория

```
course/
  index.html
  assets/   lib.js (ядро) · practice.js (тесты, повторение, термины) · engine.js и lob.js (движки симуляторов)
            lab.js, lab_book.js (лаборатория и проект) · search.js (поиск) · prereq.js (предварительные условия) · app.js (оболочка) · style.css · sources.js
  modules/  m00.js … m10.js — уроки, виджеты, тесты, глоссарий
  vendor/katex/   локальная копия KaTeX 0.16.9
tests/      run.js (юнит-тесты) · smoke.js (обход всех страниц в jsdom)
.github/workflows/pages.yml   тесты и публикация на GitHub Pages
```

Сайт статический, без сборки. Прогресс хранится в `localStorage` браузера.

## Тесты

```bash
npm install
npm test
```

`tests/run.js` проверяет структуру уроков, математику симуляторов (в том числе воспроизведение таблицы 1 статьи Avellaneda–Stoikov), интервалы повторения и то, что сайт не обращается к CDN. `tests/smoke.js` открывает каждую страницу курса в jsdom, двигает все ползунки и нажимает кнопки виджетов.

## Что стоит знать

- Часть чисел в уроках — оценки авторов курса, а не измерения: время прохождения, интенсивности потока и параметры симуляторов лаборатории.
- Симуляторы учебные: цена и единицы взяты из статьи Avellaneda–Stoikov, а не из рыночных данных. Новости и информированные трейдеры — упрощённая модель адверс-селекции.
- Уроки дважды сверены с первоисточниками (PDF): первый проход нашёл около 50 расхождений, второй добил оставшиеся непроверенные места (Harris [33], обзор MNB [31], Wilmott/Leland [12], карта чтения по всей библиотеке, порог 5% в Reg ATS по документам SEC). Что осталось: уровни сложности источников в карте чтения — субъективная оценка, а в теории индекса дисперсии для процессов Хоукса формулы в источниках нет, и урок так и говорит.
- Некоторые файлы библиотеки названы не тем, чем являются (например, «Lyons» — обзор Magyar Nemzeti Bank). Страница «Источники» в курсе показывает, что лежит в каждом файле на самом деле.
